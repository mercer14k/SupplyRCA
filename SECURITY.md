# Security policy

Version 0.1.x is a reference implementation with no security support SLA. Fixes are developed on the default branch. See docs/security.md for the threat model and local-only deployment boundary.

Please use GitHub's **Report a vulnerability** / private security advisory for the published repository if enabled. If unavailable, contact the maintainer through a private channel listed on their public GitHub profile and request a secure reporting path. Do not post credentials, private operational data or an active exploit in a public issue.

Include the affected version, minimal synthetic reproduction, impact, relevant trace IDs without secrets and suggested mitigation. Maintainers will triage privately and coordinate fixes and disclosure. No response-time guarantee is implied. Never use public demo database credentials outside localhost.
